# Ordinox Desk

**Desktop client and business management application for Windows.**

Ordinox Desk is a desktop application designed to organize client information and everyday business workflows in a simple and practical environment.

The project was developed iteratively from the initial concept into a working Windows desktop application, with a strong focus on usability, structured data management and reliable day-to-day operation.

## Key Features

- Client and business record management
- Search and filtering
- Structured data organization
- Business workflow management
- Backup and data recovery functionality
- Desktop-focused user interface
- Windows application packaging and installer

## Development Approach

Ordinox Desk was developed using an iterative, AI-assisted software development workflow.

AI coding tools, including OpenAI Codex, were used during development for implementation, debugging and refinement. Changes were reviewed and tested incrementally, with an emphasis on understanding the behavior of the application and avoiding unrelated modifications.

## Project Focus

The project demonstrates practical experience in:

- Feature implementation

- Windows application packaging
