## Παρουσίαση

Το Ordinox Desk είναι μια desktop εφαρμογή για Windows, σχεδιασμένη ώστε να βοηθά μικρές επιχειρήσεις να διαχειρίζονται πελάτες, ραντεβού, υπηρεσίες, έσοδα, υπενθυμίσεις και καθημερινές επαγγελματικές ροές από ένα ενιαίο περιβάλλον.

Στόχος είναι οι χρήσιμες πληροφορίες που αφορούν τον πελάτη και την επιχείρηση να παραμένουν οργανωμένες σε ένα σημείο, χωρίς ανάγκη για πολλά διαφορετικά spreadsheets, έγγραφα ή ξεχωριστά εργαλεία.

Η εφαρμογή ακολουθεί **local-first σχεδιασμό**, ώστε κατά την κανονική λειτουργία τα δεδομένα της επιχείρησης να διαχειρίζονται τοπικά στη συσκευή Windows του χρήστη.

Είναι σχεδιασμένη για **Windows PCs και Windows tablets**, με υποστήριξη **Αγγλικού και Ελληνικού περιβάλλοντος**.

> **Portfolio showcase:** Αυτό το δημόσιο repository παρουσιάζει την εφαρμογή και το περιβάλλον εργασίας της. Ο production πηγαίος κώδικας διατηρείται ιδιωτικός και δεν δημοσιεύεται εδώ.

> **Demo δεδομένα:** Όλα τα ονόματα, τηλέφωνα, ραντεβού, τιμές και λοιπές προσωπικές ή επαγγελματικές πληροφορίες που εμφανίζονται στα screenshots είναι φανταστικά δεδομένα επίδειξης.

## Local-First Αρχιτεκτονική

Το Ordinox Desk είναι σχεδιασμένο ώστε να λειτουργεί τοπικά στη συσκευή Windows του χρήστη.

Για την κανονική λειτουργία:

- Δεν απαιτείται remote backend
- Δεν απαιτείται εξωτερικός database server
- Δεν απαιτείται cloud account
- Τα δεδομένα αποθηκεύονται τοπικά
- Ο χρήστης μπορεί να δημιουργεί backup αρχεία
- Υπάρχει δυνατότητα restore/import
- Δεν απαιτείται συνεχής σύνδεση στο Internet

Αυτό καθιστά την εφαρμογή κατάλληλη για επιχειρήσεις που προτιμούν μια απλή standalone desktop λύση.
